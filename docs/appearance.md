# هوية المطبعة والمظهر

افتح **الإعدادات ← هوية المطبعة والمظهر**، أو اضغط زر لوحة الألوان أعلى مساحة العمل.

يمكن تغيير:

- اسم المطبعة ووصف قصير يظهر تحته.
- الشعار برفع صورة PNG أو JPG أو WebP، بحد أقصى 2 ميجابايت، مع اختيار حجمه أو إزالته.
- المظهر الليلي أو الفاتح أو التلقائي حسب إعداد الجهاز.
- لون الهوية والأزرار، ولون النص أو استخدام لون تلقائي مناسب للمظهر.
- نوع الخط وحجمه، وشكل الزوايا، والمسافات بين عناصر الواجهة.
- تقليل الحركة والمؤثرات.

توجد أربعة قوالب يمكن تعديلها: ذهب منتصف الليل، ورق وحبر، استوديو بنفسجي، وبداية منعشة. تغيير القالب لا يستبدل اسم المطبعة أو شعارها.

المعاينة مباشرة داخل صفحة التخصيص، ولا تغيّر الإعدادات المحفوظة حتى تضغط **حفظ التغييرات**. عند فشل الحفظ تبقى التعديلات في النموذج. يظهر تنبيه عند انخفاض تباين النص، ويمكن الرجوع إلى لون تلقائي.

تظهر الهوية المحفوظة في القائمة الجانبية، وشاشة الدخول، واختيار القسم، وعناوين الصفحة، ومستندات العملاء المطبوعة. تُحفظ الإعدادات ضمن قاعدة الإعدادات المحلية الموجودة، دون تعديل ملفات الطباعة أو بيانات العملاء. يعرض المسار العام `/api/branding` الهوية والمظهر فقط؛ لا يعرض إعدادات الإنتاج أو بيانات الدخول.

أُزيل شريط التنقّل القديم المضمّن داخل أدوات الإنتاج، واستُبدل بمركز تنبيهات واضح. إعدادات الصوت والتحديث والمسار موجودة في صفحات الإعدادات، والتواصل الصوتي ضمن إدارة الأقسام.

التحقق:

- `npm.cmd run lint`
- `npm.cmd run test:appearance`
- `npm.cmd run test:production`
- `npm.cmd run test:management`
- `npm.cmd run build`

يغطي اختبار Chrome الموجود في `scripts/verify-workspace.cjs` رفع الشعار، والاسم، والخط والألوان، والمظاهر الثلاثة، والتبديل التلقائي مع الجهاز، وفشل الحفظ، ووضوح الصفحات الفاتحة، والهوية في شاشة الدخول بعد الخروج. تُعترض عمليات حفظ الإعدادات خلال اختبار المتصفح، وتُستخدم قاعدة مؤقتة منفصلة في اختبارات الخادم.
