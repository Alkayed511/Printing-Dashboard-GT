# إعدادات الإنتاج

يمكن فتحها من زر الإعدادات داخل لوحة الإنتاج، أو من **الإعدادات ← إعدادات الإنتاج**.

الضبط اليومي المقترح والمفعّل:

- تحديث البيانات كل 5 ثوانٍ.
- ترتيب الملفات حسب الأولوية، ثم الأقدم داخل الأولوية نفسها.
- ترتيب الطابعات حسب عدد الملفات المنتظرة، مع إمكانية اختيار الترتيب اليدوي أو الاسم.
- فتح لوحة الإنتاج على ملفات الانتظار، وإمكانية عرض المنجز أو الكل.
- بطاقات مريحة، وملخص إنتاج صغير، وإظهار الطابعات الفارغة؛ يمكن تعديل هذه الخيارات.
- تنبيه هادئ لمدة 10 ثوانٍ، باللون الأزرق. يبقى الصوت المخصص الموجود محفوظًا.
- تأكيد قبل نقل الملفات، وتعطيل حذف الطلبات المسجلة افتراضيًا. لا يحذف التطبيق ملفات الإنتاج الفعلية من زر حذف الطلب.
- شاشة العرض للمتابعة فقط، وتُقفل تفاعلاتها في الضبط المقترح.

## المسار والطابعات يدويًا

1. أدخل المسار المطلق في **الإعدادات ← المسار ويوم العمل**، مثل `C:\PrintJobs` أو مسار شبكة مشترك.
2. أدخل اسم مجلد يوم العمل المطابق للمجلد الموجود فعليًا، مثل `30-10`.
3. اضغط **فحص المسار دون حفظ** لمراجعة إتاحة مجلد اليوم، ومجلد كل طابعة، ومجلد `done`.
4. اضغط **حفظ وتجهيز مجلدات الطابعات**. يُنشأ المسار ومجلد تاريخ العمل إذا كانا ناقصين، ثم مجلد لكل معرّف طابعة وداخله `done`. المجلدات والملفات الموجودة تبقى كما هي، وزر الفحص وحده لا ينشئ شيئًا.
5. عند إضافة طابعة، اكتب اسم مجلدها يدويًا. يُنشأ المجلد الناقص وداخله `done` عند حفظ الطابعة. المسافات مسموحة مثل `flat small`، والمعرّفات المكررة أو أسماء المسارات غير الصالحة مرفوضة. المعرّف ثابت بعد الحفظ؛ تعديل الاسم المعروض لا يعيد تسمية المجلد.

لم يتغير المسار السابق أو تاريخ العمل أو ربط الأقسام والطابعات أثناء تفعيل الضبط المقترح.

## عمليات الملفات

النقل يستخدم معرّف ملف موجود في مسح الخادم، ويتحقق من الطابعة والحالة. لا تُعرض نتيجة نجاح إذا فشل النقل، ولا يُستبدل ملف موجود في الوجهة. تُجهّز مجلدات الطابعات و`done` عند حفظ المسار أو تاريخ العمل أو إضافة الطابعات، ويمكن استكمالها بالزر المخصص حتى دون تغيير الإعدادات. حفظ المظهر أو التنبيهات وحده لا ينشئ مجلدات. عند تعذّر الإنشاء لا تُحفظ الإعدادات الجديدة؛ قد تبقى مجلدات فارغة أُنشئت قبل خطأ صلاحيات غير متوقع.

## التحقق

- `npm.cmd run lint`
- `npm.cmd run build`
- `npm.cmd run test:management`
- `npm.cmd run test:production`

اختبارات الإنتاج تشغّل خادمًا منفصلًا وقاعدة SQLite ومجلدات مؤقتة؛ لا تستخدم `.data` أو ملفات الطباعة الحقيقية. فُحصت الواجهة كذلك في Chrome على الكمبيوتر والهاتف، مع اعتراض حفظ الإعدادات خلال اختبارات المتصفح.
